## Evidence status, recalibrated so it does not overclaim
Every redesign in the evidence base that was implemented and reported is a single-course, descriptive account. Most have no control group, and quality is typically 2-3/5 (for example R81, R80 and R72). The labels are therefore:
- **Implemented in computing (descriptive evidence):** a similar redesign was implemented in a computing course (computing = Y) and its outcomes were reported. This does not show the redesign works.
- **Implemented in another discipline (descriptive evidence):** as above, outside computing. Studies flagged computing = Partial are counted here.
- **Partly implemented in computing:** the components were implemented separately but never together (Personalised tasks: R15 task design; S156 personalised viva questioning).
- **Proposal (not yet tested):** supported only by D2 ratings, author recommendations or reasoning.

## Decision guide rule (kept as drafted)
A cell is "Implemented" only if one study implemented the same main assessment and a comparable verification layer. Components tried separately leave the cell at Proposal. As a result, every sampled or risk-based verification cell for large cohorts is a Proposal. No included study measured whether sampling deters misuse; S009 proposes it but did not test it.
