# Dataset analysis: EPFL, Mircea et al. (2026) and StudyChat

Secondary analysis supporting RQ4 and the Evaluation / Recommendation Matrices.
Original dataset files in `Datasets/` are read only and were not changed.

## Main deliverable

`Dataset_Findings_EPFL_Mircea_StudyChat.xlsx`
- **Read me and methods**: definitions, statistical methods, caveats.
- **Dataset Findings**: 28 findings (11 EPFL, 9 Mircea, 8 StudyChat). Each row has the finding, the sample size, the method, the related assessment approach, the evaluation criteria, our interpretation (kept separate from the finding), limitations and the source to cite.
- Remaining sheets: supporting tables.

## How to reproduce

Run from the `IRP Working Directory` folder:

```
python Analysis/scripts/epfl_analysis.py
python Analysis/scripts/mircea_analysis.py
python Analysis/scripts/studychat_analysis.py
python Analysis/scripts/build_findings_workbook.py
```

Needs Python 3.8+ with pandas, scipy, matplotlib and openpyxl.

## Notes on interpretation

1. Our EPFL measures (fully correct, best of 8, majority of 8) are defined differently from the original paper's, so the figures here are our own results, not the paper's.
2. Findings are mapped to the eight assessment types used in the Evaluation Framework.
3. Sources: Mircea, Schmid, Droste and Schneider (EASE 2026) for the Hannover capstone survey, and McNichols, Ikram and Lan (LAK '26) for StudyChat.
4. StudyChat dialogue-act labels were generated by GPT-4.1 in the original dataset, and all StudyChat associations are observational.
5. Where a dataset's own paper is also in the review, the paper and our analysis are not counted as two separate studies.
